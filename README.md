# R Training 2026

This repository contains code and datasets from the R Training sessions held in 2026.

## Folder Structure
- **/Code**: R scripts organized by date (e.g., Day 1, Day 2).
- **/Data**: Datasets used during the training sessions.
- **/Outputs**: Graphs and tables generated from the scripts.

## Requirements
To run these scripts, you will need:
- R (version 4.x or higher)
- RStudio
- Packages: `tidyverse`, `haven`, `ggplot2`
